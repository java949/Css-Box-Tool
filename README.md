# 🚀 Css Box Tool (React + Vite)

Интерактивная веб-студия для генерации профессионального CSS кода (Box Shadows, Glassmorphism, Gradients, Blob Shapes, Text Glow & 3D, Flexbox & Grid, Keyframe Animations, Filters).

Приложение разработано на **React + Vite** с поддержкой двух языков (RU 🇷🇺 / EN 🇬🇧) и полностью готово для бесплатной публикации на **GitHub Pages**!

---

## ⚡ Особенности
- 🌐 **Двуязычный интерфейс (RU / EN)**: переключение языка в 1 клик с сохранением в браузере.
- 🌟 **Box Shadow Studio**: создание сложного многослойного внешнего и внутреннего размытия тени.
- 💎 **Glassmorphism Glass**: эффект матового стекла с регулировкой блюра, рамки и прозрачности.
- 🎨 **Gradients**: линейные, радиальные и конические градиенты с контролем цветовых точек.
- 🔮 **Border Radius & Blob**: органические плавающие формы с морфинг-анимацией.
- ✨ **Text Effects & Glow**: неон, градиентный текст (`background-clip: text`), 3D объем и контуры.
- 📐 **Flexbox & Grid Visualizer**: визуальный конструктор сеток и выравнивания элементов.
- 🎬 **Keyframe Animations**: генерация готового CSS `@keyframes` кода (pulse, bounce, spin, float, shake).
- 🎛️ **CSS Filters**: визуальный тюнинг яркости, размытия, контрастности, оттенков.
- 📋 **Экспорт кода**: копирование в 1 клик для **CSS**, **SCSS**, **Tailwind CSS** и **HTML**.
- 💾 **Библиотека сохраненных стилей**: сохранение ваших авторских настроек прямо в браузер.

---

## 🛠️ Запуск локально

```bash
npm install
npm run dev
```

Откройте в браузере: `http://localhost:5173`.

---

## 🌐 Как выложить сайт на GitHub Pages

```bash
# 1. Загрузка в основную ветку
git push -u origin main

# 2. Публикация сайта на GitHub Pages
npm run deploy
```

*(На GitHub: **Settings** ➔ **Pages** ➔ Source: **gh-pages** ➔ Save)*
